# 星の等級よみ（toukyu-yomi）

2つの星の等級を見て、明るさが何倍ちがうかを当てる1日5問の学習ゲーム。正解したら、暗いほうの星が肉眼で見えるかも選ぶ。等級の数え方・絶対等級・等級のなりたちの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/toukyu-yomi/>

- 中身は天文学辞典の「等級」<https://astro-dic.jp/magnitude/> と「絶対等級」<https://astro-dic.jp/absolute-magnitude/> に書いてあることだけです。何倍かは「1等級の違いは明るさの比で約2.512倍」から計算して丸めた値です。
- 問題に出る星A・Bは練習のための例で、本物の星ではありません（ベガ・デネブ・太陽など名前を出した星をのぞく）。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
